09 / 21
02 / 分析圖片

先看結構，再開始畫

觀察四件事

外輪廓：圓滑、稜角，還是不規則？

內部結構：面、線或碎裂紋理？

明暗：光從哪裡來？哪些面較暗？

用途：圖示、插畫，或印刷素材？

先確認「石頭本身的切面」或「表面裂紋」是哪一種需求。

02 / 查找工具

把問題換成可搜尋的詞

畫出輪廓

關鍵字：Illustrator 不規則形狀
工具方向：鋼筆、直接選取
目標：做出可調整的封閉外形。

建立切面

關鍵字：Voronoi pattern
工具方向：手動切割、形狀整理
目標：控制切面的大小與方向。

批量變化

關鍵字：Illustrated Voronoi
Randomus script
目標：生成多種形狀後再挑選修整。

找到教學後，先核對結果是否符合題目，再練習。

兩種方法，依需求選擇

14 / 21
02 / 練習操作

完成一顆簡單的石頭

第一輪：外形

畫出不規則的封閉輪廓。
先用少量節點調整比例。

第二輪：切面

先做 5–8 個大小不同的切面。
觀察分割方向是否符合外形。

第三輪：明暗

設定一個光源方向。
用幾個灰階區分亮面與暗面。

完成後請說明：你用了哪些工具？為什麼選它？哪一步最容易卡住？

02 / 案例延伸學習

從石頭案例，擴充設計可能

每遇到一個造型問題，就多認識一種方法，再想想它還能用在哪裡。

完成一顆石頭

觀察問題 · 試用工具 · 延伸應用

結構與切面

Shape Builder｜Shift + M：結合或刪除區域
Knife 刻刀：切開形狀，形成不同切面
Eraser 橡皮擦：擦除局部，修整缺口

延伸：Logo 組合、拼貼、碎裂造型

線條與粗細

Stroke 筆畫：粗細、端點與轉角
Width Tool 寬度工具：局部粗細變化
Outline Stroke / Expand：將筆畫轉為形狀

延伸：裂縫、手繪線感、字體造型

有機感與輪廓

Envelope Distort / Make with Mesh：網格扭曲
Reshape 重塑工具：調整路徑形狀
Round 圓角／圓端點：柔化稜角與線端

延伸：流體、植物、柔軟的不規則形狀

漸變與分段微調

Blend Tool 混合工具：建立中間形狀
畫路徑，再 Blend › Make：形成連續變化
分段解決：調整步數、局部路徑與節奏

延伸：層次紋理、流動線條、漸變圖案

案例完成後，再問一次：「換個形狀、粗細或組合，會產生什麼設計？」將解題過程累積成可重複運用的方法。需要合併線條外形時，再使用 Outline Stroke 或 Expand。

03 / 課程目標

工作應用，或證照準備？

以工作為目標

先整理常見任務與交付規格。
從最常用、最耗時的問題開始。
觀察是否更快完成，修改是否更精準。

以證照為目標

先確認考試名稱、版本與預計日期。
依考綱規劃基礎練習與模擬題。
保留工作實作，理解工具的用途。

討論欄：最優先的目標＿＿＿＿　希望完成的時間＿＿＿＿
